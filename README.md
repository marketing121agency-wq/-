# Motion skills

Скиллы для моушн-анимации в Claude Code. Лежат в `.claude/skills/` и подключаются автоматически в каждой сессии с этим репозиторием.

- **Remotion** (`remotion-*`) — видео и моушн-графика на React. Источник: [remotion-dev/skills](https://github.com/remotion-dev/skills)
- **GSAP** (`gsap-*`) — веб-анимация, таймлайны, ScrollTrigger. Источник: [greensock/gsap-skills](https://github.com/greensock/gsap-skills)
